Упражнение 3. Погрешность косвенного измерения плотности

  1. σ(ρ̄) = ρ̄·√((σ(h̄)/h̄)² + 4(σ(d̄)/d̄)²) = 2701·√((0,049/39,98)² + 4·(0,032/15,0)²) = 2701·√(1,50·10⁻⁶ + 1,78·10⁻⁵) = 2701·0,00439 = 11,9 кг/м³.
  2. t(0,95; 5) = 2,78.
  3. Δρсл = 11,9·2,78 = 33 кг/м³.
  4. Δs(ρ̄) = 1,1·ρ̄·√((Δs(m)/m)² + (Δs(h)/h̄)² + 4(Δs(d)/d̄)²)
    = 1,1·2701·√((0,01/19,07)² + (0,1/39,98)² + 4·(0,1/15,0)²)
    = 1,1·2701·√(2,75·10⁻⁷ + 6,26·10⁻⁶ + 1,778·10⁻⁴) = 1,1·2701·0,01358 = 40 кг/м³.
  5. Δs(ρ̄)/σ(ρ̄) = 40,3/11,9 = 3,4.
  6. 0,8 ≤ 3,4 ≤ 8, поэтому k = 0,73 (по таблице для 3):
    Δ(ρ̄) = k[Δs(ρ̄) + σ(ρ̄)·t] = 0,73·(40,3 + 33,0) = 54 кг/м³.
  7. ρ = 2701 ± 54 кг/м³ ≈ (2,70 ± 0,05)·10³ кг/м³.
  8. δ(ρ̄) = 54/2701·100% = 2,0%.
