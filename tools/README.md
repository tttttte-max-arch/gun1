# Проверки карты

Скрипты гоняют `angar.html` в headless Chromium (Playwright, программный
рендерер SwiftShader) и проверяют то, что глазами на скриншоте не увидеть:
проходимость, физику, свет и стоимость кадра.

## Запуск

```sh
python3 tools/serve.py &                 # http://127.0.0.1:8099
npm i -g playwright && npx playwright install --with-deps chromium
ln -s "$(npm root -g)/playwright" node_modules/playwright

node tools/probe.mjs     # сборка сцены: меши, вызовы отрисовки, треугольники
node tools/report.mjs    # статистика карты + автопроверка лестниц
node tools/nav.mjs high  # достижимость 23 контрольных точек (флуд-фил в 3D)
node tools/phys.mjs      # ткань, порывы ветра, разрушаемость, обломки
node tools/day.mjs       # суточный цикл: солнце, луна, прожекторы, экспозиция
node tools/perf.mjs      # стоимость кадра на всех четырёх профилях качества
node tools/soak.mjs      # длительный прогон: сутки + разрушения + ходьба
bash tools/syntax.sh     # синтаксис модуля без запуска браузера
```

## Что считается провалом

- `nav.mjs` — `UNREACHABLE` больше нуля: часть карты отрезана.
- `report.mjs` — непустой `stairIssues`: на марш что-то нависло.
- `perf.mjs` — заметный рост `calls`: сломалось запекание статики.
- любой скрипт — непустой `errors`.

Проверка лестниц продублирована в самой карте (`auditStairs`) и пишет
предупреждение в консоль при загрузке, потому что реквизит расставляется
процедурно и перекрыть марш может любое смещение координат.
